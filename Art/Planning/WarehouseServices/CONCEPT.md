# 물류창고 설비 디테일 구상

2026-10-14 조사·작성. `warehouse_services_concept.png`는 현재 맵 캡처와 문서의 공간 구성을 참고한 AI 생성 제안 이미지다. 실제 맵의 정확한 좌표·구조를 복제한 화면이나 완료된 모델링 결과는 아니다. 이 구상도 작성 당시에는 에셋 제작·맵 변경을 수행하지 않았다. 이후 제작한 모듈의 상태·검증은 [WAREHOUSE_SERVICES_MODEL.md](../../../../WAREHOUSE_SERVICES_MODEL.md)를 참조한다. 현재 맵과 관찰 모드 기준은 [WAREHOUSE.md](../../../../WAREHOUSE.md), 복층은 [MEZZANINE.md](../../../../MEZZANINE.md)를 따른다.

## 조사에서 가져온 시각 요소

- 산업용 철골 창고의 주 보·보조 부재·가새·볼트 접합부: [Steel Construction Info](https://steelconstruction.info/sectors/single-storey-industrial-buildings). 현재 기존 기둥·복층을 기준으로 필요한 시각 디테일을 더하는 안이며 구조 재설계가 아니다.
- 산업용 케이블 트레이와 벽면 지지 브래킷: [Legrand 산업 솔루션](https://www.legrand.us/industrial), [벽면 트레이 지지 부품](https://www.legrand.us/wire-and-cable-management/cable-tray-and-reels/wire-mesh-trays/wire-mesh-cable-tray-wall-mounting/p/series-wire-mesh-wall-supports). 상부 주 트레이 → 벽면/기둥 수직 분기 → 분전함·접속함 → 충전기/조명의 연결 경로를 제안한다.
- 창고 천장·랙 주변 소방 설비: [Viking 고층 저장창고 기술 자료](https://www.vikinggroupinc.com/sites/default/files/documents/High%20Bay%20Storage.pdf). 이미지의 붉은 배관과 헤드는 시각 콘셉트다. 실제 소방 설계·간격·규정 적합성을 제시하지 않는다.
- 높은 공간의 기류 보조 설비 사례: [Big Ass Fans 설계 안내](https://learn.bigassfans.com/design-guide). 대형 팬은 선택 항목으로 보류하고, 이번 그림에는 외곽의 제한된 환기 덕트·그릴만 제안했다. 팬 설치 시 조명·소방·복층 간섭을 별도로 검토해야 한다.

## 이 프로젝트에 적용할 제안

1. **먼저:** 기존 보·기둥에 접합판과 가새 디테일을 더하고, 천장 케이블 트레이·행거·충전기 벽면 전선관/분전함을 만든다. 빈 천장과 벽이 가장 크게 달라지는 영역이다.
2. **다음:** 소방 주 배관과 분기, 조명 브래킷·전원 연결을 더한다. 트레이·배관·조명이 서로 관통하지 않도록 연결점과 높이를 분리한다.
3. **마무리:** 외곽 환기 덕트·그릴, 접속함·고정 클램프, 작은 번호표와 절제된 먼지·표면 사용감을 더한다.

기존 0/4/8m 복층과 12m 지붕 구성을 기준으로 지붕 아래 주 설비와 복층 바닥 아래 분기를 구분한다. 그림은 이를 설명하는 시각 제안이며 실제 치수 배치는 모델링 시작 전에 현 맵의 구조를 확인해야 한다. 승강기 수직 이동 구간·문, AGV/적재물 통로, 랙 사용 공간은 비워둔다. 충전기 주변은 벽면을 따라 전선관을 연결하고 바닥 케이블을 만들지 않는다.

반복 키트: 트레이 직선/90도 엘보/T 분기, 행거/벽 브래킷, 전선관 직선/엘보/클램프, 접속함·분전함, 배관 직선/T/헤드/지지대, LED 조명, 덕트 직선/엘보/그릴. 먼 케이블 다발은 단순 형상과 재질로 표현하고 가까운 분전함·충전기 주변만 상세 모델링한다. 기존 관찰 모드의 지붕·층별 숨김에 맞는 그룹화와 반복 인스턴싱을 검토한다.

## 실제 확인 범위

2026-10-14 현재 맵 문서·복층 문서·충전기 적용 캡처와 위 공개 자료를 읽고 구상도를 생성·검토했다. 현 맵 천장 전체의 좌표 실측, 새 메쉬 배치, 충돌/성능 검사는 하지 않았다. 그림의 조명·배관·분전함 위치와 설비 밀도는 제안 단계다.
